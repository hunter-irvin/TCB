# TCB

Tournament team builder app for drafting roster and team configurations.

## Local development

1. Run `npm install`
2. Create `.env.local` from `.env.example`
3. Set:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. Run `npm run dev`
5. Open `http://localhost:3000`

## Routes

- `/roster`
- `/teams`
- `/matchup-tinder`
